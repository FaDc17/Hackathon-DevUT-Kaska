INSTRUCCIONES PARA ABRIR EN WINDOWS
1. Extrae el ZIP COMPLETO, no abras los archivos directamente dentro del comprimido.
2. En Visual Studio Code: Archivo > Abrir carpeta y selecciona esta carpeta, la que contiene package.json.
3. Abre Terminal > Nuevo terminal (PowerShell) y ejecuta:
       npm.cmd install
       npm.cmd run build
       npm.cmd run dev
4. Abre la URL local indicada por Vite, normalmente http://localhost:8443/.
5. Inicia sesión > ¿Necesitas ayuda? > Agente Kuska.
6. Pruebas online: 'Busco una pollería por menos de 50 soles en Bellavista'.
   El resultado cloud actual procede de datos DEMO en Cloudflare, NO de Azure.
7. Prueba con un proveedor local precargado: 'Busco un electricista en Breña'.
   Podrás abrir la ficha de servicio, el perfil de David Cruz y el mapa general.
8. Sin internet (con app ya abierta): solicita 'Abre Comunidad' o 'Busco un electricista en Breña'.
   Los resultados locales pueden estar desactualizados; no hay IA generativa offline.
